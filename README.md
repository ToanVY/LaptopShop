# LaptopStore

Website bán laptop PHP + MySQL với các tính năng:
- Trang chủ, danh sách sản phẩm, chi tiết sản phẩm
- Giỏ hàng và thanh toán
- Trang admin để quản lý danh mục, sản phẩm, đơn hàng và thống kê

## Cài đặt
1. Khởi động Apache + MySQL (XAMPP)
2. Tạo database `LaptopStore` hoặc để hệ thống tự tạo khi truy cập lần đầu
3. Truy cập `http://localhost/LaptopStore1/`
4. Admin: `http://localhost/LaptopStore1/admin/login.php`
   - Tài khoản: `admin`
   - Mật khẩu: `admin`
